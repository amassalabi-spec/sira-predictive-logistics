This is SIRA, an IA/logistics dashboard for the PORTNET plateform built for real time monitoring shipments, reducing costs and supporting data-driven decision-making.

The platform provides a centralized dashboard where logistics managers can track shipments, analyze operational performance, identify potential disruptions, and leverage predictive models to anticipate future demand and delivery risks. By transforming logistics data into actionable insights, SIRA enables organizations to improve efficiency, reduce operational costs, and enhance supply chain resilience.

## Key Features

- 📦 Real-time logistics and shipment monitoring
- 📈 Predictive analytics for demand and delivery forecasting
- 🚚 Route optimization and operational insights
- 📊 Interactive dashboards and performance metrics
- ⚠️ Early detection of delays and supply chain risks
- 🔍 Data-driven decision support for logistics planning
- 📱 Responsive and modern user interface

## Technology Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Modern Data Visualization Libraries
- AI & Predictive Analytics Models
- Vercel Deployment Platform
  (this project has been vibecoded, to be honest :))


SIRA empowers organizations to move from reactive logistics management to proactive, predictive operations by leveraging artificial intelligence and advanced analytics to anticipate challenges before they occur and optimize every stage of the supply chain.
